Price chart

 

Recent candles: main Minswap SNEK/ADA pool via GeckoTerminal, last candle refreshes every 60 s. Older candles come from a history file the site’s GitHub Action grows every day: on-chain candles for the last ~180 days, and before that Gate.io SNEK/USDT (marked “CEX · Gate”; the ADA view divides by Gate ADA/USDT). Daily and 4H go back to Dec 27, 2023 (Gate listing); scroll left to load older candles. Pinch or scroll to zoom, drag to pan. Times in CT. Charting by TradingView Lightweight Charts™.
